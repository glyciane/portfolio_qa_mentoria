# Testes Exploratórios

Sessões de teste exploratório, documentadas com **charter** (o que testar,
por quanto tempo, com qual objetivo) e notas do que foi observado.

Sugestão de nomenclatura: `sessao-01-despesas.md`, `sessao-02-relatorio.md`, etc.

## Modelo de charter

```markdown
# Sessão XX — [área testada]

**Charter:** Explorar [funcionalidade] a fim de descobrir [tipo de problema],
usando [técnica/abordagem].

**Duração:** XX min
**Data:** DD/MM/AAAA

## Notas da sessão
- ...

## Bugs encontrados
- Link para a Issue correspondente

## Perguntas / dúvidas levantadas
- ...
```
