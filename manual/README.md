# Testes Manuais

Execução manual dos casos de teste definidos em `docs/casos-de-teste.md`.

- `evidencias/` — prints, respostas de API (via Postman/Insomnia) e logs
  coletados durante a execução, organizados por caso de teste
  (ex: `CT001-login-valido.png`)

## Registro de execução

Sugestão: manter uma planilha ou tabela em Markdown com o resultado de cada
caso executado (Passou / Falhou / Bloqueado), com link para a evidência e,
se aplicável, link para a Issue do bug encontrado.
